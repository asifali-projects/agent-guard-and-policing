# Presentations

Three ready-to-present PowerPoint decks. Source generators live in the repo
history under `scratchpad` — regenerate with `node build.js` (needs `pptxgenjs`).

| Deck | Audience | Use it to… | Slides |
|------|----------|-----------|--------|
| [`AgentGuard-GTM-Client-Presentation.pptx`](AgentGuard-GTM-Client-Presentation.pptx) | Prospective customers, buyers, execs | Pitch the whole product — the problem, the value, the platform, enterprise readiness, pricing tiers | 16 |
| [`AgentGuard-SDK-Developer-Guide.pptx`](AgentGuard-SDK-Developer-Guide.pptx) | Developers integrating AgentGuard | Hand to an engineering team as the SDK onboarding — install, quickstart in 3 languages, the decision contract, config, fail-safe, CLI, CI/CD gate | 15 |
| [`AgentGuard-Project-Walkthrough.pptx`](AgentGuard-Project-Walkthrough.pptx) | New engineers, reviewers, technical evaluators | Walk someone through the codebase — layout, architecture, the critical path, the auth spine, the data model, the clients, the build process | 17 |

The walkthrough deck's "Start here" slide mirrors [`../CODE_TOUR.md`](../CODE_TOUR.md),
the guided reading order for the source.

All three are 16:9, self-contained (safe fonts: Cambria / Calibri / Courier New),
and open in PowerPoint 2016+ / Google Slides / Keynote.
